# 库存管理用户手册

这是一款在你自己的电脑上管理商品库存的桌面应用。所有数据都保存在本地，
不会上传到互联网。

## 1. 安装并启动应用

**macOS**

1. 找到 `InventoryManagement.app`（位于下载包的 `build/desktop/` 目录中，
   或者管理员放置的位置）。
2. 将其拖入 **应用程序** 文件夹（推荐）。
3. 首次打开时，由于应用未签名，macOS 会弹出安全提示。请 **右键点击 → 打开**，
   在确认对话框中点击 **打开**。之后即可正常双击启动。

**Windows**

1. 在 `InventoryManagement` 文件夹中找到 `InventoryManagement.exe`。
2. 双击运行。
3. 首次启动时，Windows SmartScreen 可能提示「Windows 已保护你的电脑」。
   请点击 **更多信息 → 仍要运行**。
4. 在 Windows 10 上，如果窗口没有出现且没有报错，请从微软官网安装免费的
   **Microsoft Edge WebView2 运行时**，然后重新启动应用。（Windows 11
   已经预装。）

应用窗口会自动打开。你**不需要**额外启动其他任何程序，应用是完全独立的。

## 2. 选择语言

在登录页、注册页或库存页面顶部使用 **语言** 选择器。

- 选择 **English** 使用英文。
- 选择 **中文** 使用中文。
- 你的选择会在当前电脑上保留。

## 3. 创建账户

第一次启动应用时，由于尚未存在任何账户，会自动打开 **欢迎** 注册页面。

1. 输入用户名。
2. 输入至少 6 个字符的密码。
3. 再次输入密码进行确认。
4. 如果希望在重启后仍保持登录，勾选 **记住我**。
5. 点击 **创建账户**。

只要至少存在一个账户，下次启动应用时就会先显示登录页。你仍然可以从
登录页点击 **创建一个** 注册新的账户。

## 4. 登录与退出

登录步骤：

1. 输入用户名。
2. 输入密码。
3. 如有需要勾选 **记住我**。
4. 点击 **登录**。

退出应用时，可以点击库存页面顶部的 **退出登录** 按钮，或者直接关闭窗口。

## 5. 查看仪表盘

库存页面顶部会显示：

- **商品总数**：当前账户中的所有商品数量。
- **低库存**：库存低于该商品补货阈值的商品数量。
- **缺货**：库存为 0 的商品数量。
- **默认补货提醒**：未设置自定义阈值时使用的默认阈值。

每个用户只能看到自己的库存数据。

## 6. 新增商品

使用左侧的 **新增商品** 表单。

1. 输入唯一的 **SKU**。
2. 输入 **商品名称**。
3. 输入初始 **库存数量**。
4. 可以选择设置 **低库存提醒** 阈值。
5. 可以选择添加 **自定义字段**（分类、供应商、颜色、货架、成本等）。
6. 点击 **新增商品**。

你输入的初始库存会自动作为商品库存历史的第一条记录保存。

## 7. 查找和查看商品

使用搜索框按 SKU 或商品名称筛选。

- 点击 **搜索** 应用筛选，点击 **重置** 清空搜索。
- 使用 **上一页** 和 **下一页** 翻页。
- 点击商品行中的 **查看** 在右侧加载商品详情。
- 也可以在 **获取商品** 区域输入商品 ID 后点击 **获取商品**。

## 8. 更新或删除商品

更新商品信息：

1. 使用 **查看** 或 **获取商品** 加载商品。
2. 修改 SKU、名称、低库存阈值或自定义字段。
3. 点击 **保存更改**。

**库存数量** 字段在编辑时会被锁定 — 修改库存请参考第 9 节。

删除商品：

1. 点击商品行中的 **删除**，或加载商品后点击 **删除商品**。
2. 重新输入密码进行确认。
3. 点击 **删除**。

## 9. 管理库存

库存只能通过商品行的按钮变更，不能直接编辑商品。每一次操作都会带时间戳、
数量变化和可选备注记录到历史中。

- **入库**：增加库存（到货或退货）。弹窗中可以选择原因 — *到货入库* 或
  *客户退货*。
- **出库**：减少库存（销售、使用、损坏、丢失）。弹窗中可以选择原因 —
  *已售出或已使用* 或 *损坏或丢失*。
- **调整**：盘点或修正后设置库存的绝对数量。可以调整到 0。
- **历史**：查看该商品的近期库存变更列表。

填写备注会很有帮助 — 例如供应商名称、销售单号、盘点说明、损坏原因等。

如果出库数量大于当前库存，应用会拒绝操作并提示当前实际剩余数量。

## 10. 导出商品

点击顶部的 **导出** 可下载完整商品列表为 `products.csv`，文件会保存到
电脑默认的下载位置。

## 11. 管理账户

- **编辑资料**：修改用户名，需要用当前密码确认。
- **修改密码**：输入当前密码后设置新密码（至少 6 个字符；像 `123456`
  这样的常见密码会被拒绝）。

## 12. 备份与重置

应用会把所有数据保存在电脑标准的应用数据目录中。复制该目录即可备份，
删除该目录即可重置。

| 系统    | 目录                                                                  |
|---------|-----------------------------------------------------------------------|
| macOS   | `~/Library/Application Support/InventoryManagement/`                  |
| Windows | `%LOCALAPPDATA%\InventoryManagement\InventoryManagement\`             |

目录中包含：

- `inventory.db` — 所有商品、用户和库存历史。
- `secret_key` — 用于签名你的登录会话，请勿分享。
- `logs/` — 应用日志（反馈问题时很有用）。

**备份方法**：将整个目录复制到安全位置。

**恢复方法**：关闭应用后，用备份替换该目录。

**重置方法**：关闭应用并删除该目录。下次启动时会创建一个全新的数据库，
并提示你重新注册。

## 13. 常见问题

- **Windows 上窗口没有打开**：请安装微软官网免费的 Microsoft Edge
  WebView2 运行时，然后重新启动应用。
- **「Windows 已保护你的电脑」**：点击 **更多信息 → 仍要运行**。这是因为
  当前构建尚未进行代码签名。
- **macOS 提示「无法打开，因为无法验证开发者」**：右键点击应用 → **打开** →
  在弹窗中再次点击 **打开**。
- **用户名或密码无效**：请检查登录信息后重试。连续 5 次失败后，账户会被
  临时锁定 15 分钟。
- **SKU 已存在**：每个账户内的 SKU 必须唯一。
- **无法出库 N 件：当前仅剩 M 件库存**：本次出库会让库存变为负数。
  请先入库或减少出库数量。
- **会话已过期**：请重新登录。
- **忘记密码**：应用不支持密码重置 — 请关闭应用，删除第 12 节中目录里的
  `inventory.db`，然后重新启动并注册账户。（这样会丢失所有商品数据，
  如有需要请先备份。）
